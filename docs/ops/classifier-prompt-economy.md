# Экономия промпта классификатора: что уходит в DeepSeek и почему

> Замер 10.11.2026 по журналу воркера на проде (`deepseek-usage`) и по живым
> выборкам. Все числа — факт из журнала, не оценка.

## Что такое «промпт» нашего классификатора

Один вызов модели = **один чанк** (≈3 поста одного региона). Промпт собран из
трёх частей:

| Часть | Откуда | Размер (прод, 10.11) |
|---|---|---|
| базовый файл правил | `config/classification_postulates.md` (git) | 12 638 симв. |
| словарь тем | БД `classifier_themes` + описание границ | ~700 симв. |
| выученные правила | БД `classification_rules` (34 approved) | 12 815 симв. |
| **всего** | | **27 337 симв. ≈ 10 514 токенов** |

Замер снят скриптом [`scripts/probe_postulates_size.py`](../../scripts/probe_postulates_size.py).

## Куда уходят деньги (09.11, наш счёт)

| Потребитель | вызовов | prompt | из него miss (полной цены) | completion |
|---|---|---|---|---|
| `headless` — классификатор | 636 | 7,91M | 1,46M | 428K |
| `discovery` — разовый свип 04:00–04:29 | 2552 | 2,15M | 2,15M | 151K |
| `post_rewrite` — волны | 364 | 348K | 160K | 92K |
| `daily_digest` — сборники | 75 | 128K | 119K | 28K |
| `conveyor` — сайты | 8 | 24K | 5K | 1,6K |

Кэш префикса работает: `headless` — **84 % hit**, `discovery` — **0 %** (у него
инструкции стоят ПОСЛЕ данных группы, кэшировать нечего).

## Главная метрика: токенов на один пост

| | 08.11 | 09.11 |
|---|---|---|
| токенов на чанк | 11 578 | 11 378 |
| постов на чанк (в среднем) | 3,7 | **2,9** |
| **токенов на классифицированный пост** | 3 142 | **3 931** |

Причина простая: **префикс правилника ~10 300 токенов едет в каждом вызове**,
а чанк — это в среднем 2,9 поста. Отсюда и «дорогой» пост: 92 % его стоимости —
это правилник, повторённый 636 раз в сутки.

Прямые следствия из журнала:
- `posts=1 chunks=1 tokens=10569` — **один пост стоит 10 569 токенов**;
- 83 % всех prompt-токенов дня — это 6,6M повторов правилника.

## Что уже проверено и НЕ является причиной

- **Повторной классификации нет**: 206 000 строк вердиктов = 206 000 разных
  `lip`, дублей 0.
- **«Раздумья» модели выключены** (`thinking: disabled`, ADR-0014) — в журнале
  `reasoning=-`, оплаченных за рассуждение токенов нет.
- **Кэш префикса работает** (84 % hit) — переставлять промпт ради кэша нечего.

## Рычаги (по деньгам)

1. **Длина префикса.** Единица экономии при платном провайдере — длина
   неизменяемого префикса (R29 мозга, амендмент 07.11 по замеру Матрицы РМЗ).
   Сжатие базы 12 638 → 8 871 символов (−30 %) тянет за собой и выученный слой
   в процентах промпта.
2. **Число вызовов.** Префикс платится **за вызов**, а не за пост. Пока чанк —
   один регион, а постов в нём 2,9, платить приходится 636 раз в сутки.
   Крупнее чанк (несколько регионов в одном вызове) — рычаг в 3–5 раз, но
   требует проверки: `merge_with` не должен пересекать регионы, а ответ не
   должен обрезаться по `max_tokens`.
3. **Локальный движок** — убирает облачную цену входа целиком (см.
   [мост](local-engine-bridge.md)).

## Сжатие базы: приёмка

Сжатая версия — [`config/classification_postulates.md`](../../config/classification_postulates.md)
(в git-истории — прежняя, полная версия; правила не переписывались по смыслу,
убраны дата решения, обоснование и повторы).

Приёмка — измерителем [`scripts/classifier_postulates_ab.py`](../../scripts/classifier_postulates_ab.py):
на **одних и тех же постах** (золотая выборка — правки оператора) сравниваются
действующие постулаты и сжатые, и считается согласие с решением оператора.

| Выборка | вариант A (действующий) | вариант B (сжатый) | дельта |
|---|---|---|---|
| 60 постов | action 76,7 % | action 71,7 % | −5,0 п.п. (шум: 1σ ≈ 5,6 п.п.) |
| **150 постов** | action **82,0 %** | action **86,7 %** | **+4,7 п.п.** |
| 150 постов | theme 66,7 % (n=9) | theme 66,7 % (n=9) | 0 |

Разбор расхождений показывает, где выигрывает сжатый: на «Профилактика ОРВИ»
(A — delete, B — publish по правилу о практических памятках, оператор — publish),
на анонимной жалобе без контакта (A — hold, B — delete, оператор — delete) и
ещё на нескольких. То есть сжатие **не только не хуже — оно решительнее** там,
где действующий текст размывал правило повторениями и оговорками.

Размер промпта: 27 337 → 23 570 символов (−13,8 %), ≈10 514 → ≈9 065 токенов.

## Что осталось на столе

- **Выученный слой — 47 % промпта** (12 815 символов, 34 правила). Часть
  правил покрыта базой; кандидаты на вывод — по aging (#033), решение за
  владельцем.
- **Крупнее чанки** — рычаг в 3–5 раз по числу вызовов, но с проверкой
  качества и обрезки ответа.
- **Локальный движок** — [мост](local-engine-bridge.md).

## Связи

- ADR-0014 — DeepSeek напрямую, раздумья выключены, кэш префикса.
- R29 мозга — «при платном провайдере единица экономии — длина неизменяемого
  префикса, а не свой бинарь».
- P224 — эта работа в реестре.

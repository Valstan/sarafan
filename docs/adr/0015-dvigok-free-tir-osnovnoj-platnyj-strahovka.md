# ADR-0015 — Движок: free-тир основной, платный DeepSeek — страховка

## Контекст

- **ADR-0014** (решение владельца 06.11): движок — DeepSeek API напрямую
  (`CLASSIFIER_ENGINE=deepseek`), self-hosted контур выведен из эксплуатации.
  Причина — платный API дешевле и надёжнее выдолбленного контура.
- **Замер 11.11 (прод):** free-тир платформы отвечает **с IP бокса** — гейта по
  IP больше нет (ADR-0014 его закрывал весь каталог). Но его **квота аккаунта**
  кончается: демон сделал 70 вердиктов за сутки, а к 23:30 МСК отказ был
  явным — `quota_exhausted http_429: Free usage limit reached`.
- **Цена платного API (замер по логам за 7 суток, 11.11):** 5 717 вызовов,
  27.07 млн токенов, доля кэша 67.6 % → **≈$2.5–5.0 в неделю**
  ($0.35–0.70 в сутки) по тарифу `deepseek-flash`. Баланс счёта — 14.79 $.
- **Решение владельца (11.11):** «конечно на опенкод переключи, там фри-тир,
  ну когда фритир отвалится то работай платным апи дипсика, а на следующие
  сутки снова включай опенкод, там фри тир должен заработать».

## Решение

1. **Free-тир — основной движок, платный DeepSeek — страховка.**
   `CLASSIFIER_ENGINE=opencode` + `CLASSIFIER_PAID_FALLBACK=1`.
2. **Отказ free-тира закрывает платный Дипсик.** Раньше переключатель выбирал
   один движок: на исчерпанной квоте волна оставалась без вердиктов (fail-open,
   посты по обычным фильтрам). Теперь отказ free-тира — не отказ волны.
3. **Предохранитель остаётся счётчиком free-тира.** Успех платного Дипсика его
   не закрывает: иначе квота, которую нельзя снять повтором, опрашивалась бы на
   каждом чанке — и волна платила бы, ни разу не попробовав бесплатный путь.
4. **Возврат на free-тир — автоматический.** Пауза
   `ENGINE_BREAKER_QUOTA_COOLDOWN` истекла → free пробуется снова; как только
   суточная квота сбросилась, следующий вызов снова идёт в free-тир. Ручной
   переключатель по таймеру не нужен: «сбросилась квота» и есть условие
   возврата.
5. **Отключение страховки — одним env:** `CLASSIFIER_PAID_FALLBACK=0`. Когда
   платить нельзя (счёт пуст, оплата закрыта), волна идёт по обычным фильтрам,
   а не тратит.
6. **Параметры волны под free-тир.** Free-модели медленнее платного API
   (замер демона 11.11: 2–3 поста за 17–70 с, то есть ~10–25 с на пост против
   ~1 с у DeepSeek), поэтому чанк волны уменьшен и потолок вызова поднят:
   `CLASSIFIER_HEADLESS_CHUNK=5`, `CLASSIFIER_HEADLESS_REGIONS_PER_CHUNK=2`,
   `OPENCODE_PUBLISH_TIMEOUT=120`. Склейка `merge_with` судится внутри района —
   это и было требование к движку от 19.10.
7. **Пароль serve — из файла, который serve пишет сам.**
   `opencode serve` перевыпускает пароль при каждом рестарте, поэтому значение
   в env-файле бокса молча устарело бы: волна получала бы 401 на каждом вызове
   после рестарта. Клиент берёт пароль из `~/.config/opencode/service.json` —
   как это уже делает демон моста.
8. **Адрес serve задаётся явно:** `OPENCODE_BASE_URL=http://127.0.0.1:4097`
   (дефолт в коде — 4096, а на боксе движок слушает 4097; без этого волна
   ходила бы в пустоту и молча уходила бы в платный Дипсик).

## Чем мы за это платим (честно)

- **Экономия небольшая.** Квота free-тира накрывает ~70–100 постов в сутки
  (замер 11.11) против ~700 постов в сутки у нас, то есть **около 10 %** объёма;
  в деньгах это ≈$0.05–0.10 в сутки (≈$1.5–3 в месяц).
- **Волна идёт медленнее, пока квота жива.** ~10–25 с на пост против ~1 с:
  волна из ~67 постов занимает ~12–25 минут вместо ~2. Публикация по часовому
  расписанию это переживает, но задержка вердикта — реальная.
- **Пока квота кончена, платим как раньше** — платный Дипсик, с его ценой и
  его задержкой.

## Альтернативы

- **Оставить волну на платном API** (ADR-0014) — волна быстрая и предсказуемая,
  free-тир работает только как дополнение демона. Отклонено решением
  владельца 11.11.
- **Переключать движок руками по суточному таймеру** — отклонено: «сбросилась
  квота» проверяется сама, и лишний переключатель был бы источником ошибок
  (ручное движение движка в проде — гейт без машины).

## Что осталось за владельцем

- **Продление free-тира через ВПН-плечо.** Механика в репозитории цела
  (`infra/neural/`, автоповорот выхода `NEURAL_EGRESS_ROTATE_CMD`, смена адреса
  снимает per-IP гейт за 1,7–2,6 с). Не хватает **подписки NextGenVPN**:
  контур снят с бокса 11.11 вместе с `/etc/neural`, в комнате `setka` её нет.
  Нужна ссылка подписки — положить в комнату под именем
  `NEXTGENVPN_SUBSCRIPTION_URL`.
  ⚠️ Замер 25.10: **смена адреса не снимает квоту аккаунта** (пять поворотов подряд —
  DE, PL, NL, US, PL — не помогли). ВПН-плечо лечит **per-IP** гейт и
  per-IP 429, но не «Free usage limit reached». То есть подписка расширит
  доступный free-объём, но не снимет суточную квоту аккаунта.

## Последствия

- Панель `/local-engine` теперь показывает режим волны прямо: «Волну считает:
  Опенкод — бесплатный тир» и разрез «кем отвечено» по моделям.
- Откат на платный API — **одна переменная** на боксе
  (`CLASSIFIER_ENGINE=deepseek`) плюс рестарт; страховка при этом всё равно
  включена, но звать её будет нечего.

## Failed approaches этой нитки

- **Эпоха маркера руками.** Время прогона в Redis вписано числом «на глаз» — оказалось 13.09 вместо 06.10, интервал вышел «22д22ч». Правило: epoch только из лога (`pilot run note sent`), считается кодом, не головой.
- **Охота на дырку в middleware.** Час дебага свежих `//wp/...` серий кончился доказательством, что виноваты файлы июня (PID-коллизия с grafana), а живой код невиновен (пробы UUID → unmatched). Урок: свежесть данных проверять раньше кода — `mtime` файлов раньше чтения исходников.
- **Pre-commit на неотслеживаемых файлах.** Локально зелёный, CI красный: `pre-commit run --all-files` берёт файлы из `git ls-files`, новые не видит. Лечится `git add` до прогона гейта.
- **Текст в командной строке.** PowerShell-редирект `>` пишет не-UTF-8 и роняет файлы; кавычки съедаются слоями ssh. Рецепт канона — только через файлы — подтверждён в очередной раз.
- **Direct push в main.** Лента переговорной ушла напрямую, откачена `reset --soft` и проведена через PR #858. Проверять ветку до коммита.

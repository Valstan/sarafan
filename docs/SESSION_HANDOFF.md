## Failed approaches (этой нитки)

- **Значение ключа читать из DOM, а не из `inspect`.** `inspect` отдаёт текст поля обрезанным (100
  символов) — такой токен уходит в БД битым: `[5] User authorization failed: invalid access_token`.
  Рабочий путь — `query(kind="dom", selector='input[value*="vk1"]')`, там `value` целиком (220).
- **Файл на прод передавать через base64, а не конвейером PowerShell.** `Get-Content -Raw | ssh`
  дописывает `\r\n`: токен приезжал длиной 222 вместо 220 и не проходил валидацию.
- **`groups.edit` ждёт параметр `city` (строка), а не `city_id`.** С `city_id` вызов проходит без
  ошибки, а город **молча не меняется** — проверять чтением `groups.getById(fields="city")` сразу
  после записи.
- **Push-подтверждение ВК живёт около 10 минут.** Два запроса подряд истекают молча — страница
  возвращается к пустому списку ключей. Рабочий режим: **один ключ за раз**, значение читать сразу
  после подтверждения. Страница «Не пришло уведомление?» открывается сама, когда окно истекло: там
  есть повторный запрос push и запасной канал **SMS**.
- **`groups.edit` через API — `[3] Unknown method passed` на 5.103/5.131/5.199**, если токен
  **пользовательский**. Community-ключом работают и `description`, и `city`; `screen_name` — только
  user-токеном ⇒ короткий адрес руками в браузере.
- **Короткий адрес у `leninogorsky` / `bugulminsky`** — activity «Публичная страница», «Тематика»
  пустая, ВК отклоняет сохранение целого блока «Основная информация». Владелец решил не
  пересоздавать группы (21.11) — вопрос закрыт.
- **`--repair` до `--apply` по новым группам** — repair ставит аватар user-токеном, группа
  перестаёт быть «голой», и full-режим `--apply` больше не срабатывает.
- **Стена/предложка — не через «Контент» → «Посты» → «Настроить»**: клик попадает в переключатель
  показа раздела и **выключает** его. Рабочий путь — `?act=sections`.
- **`sudo bash <скрипт>` на проде** — хост-гейт режет форму; работает
  `sudo bash -c 'set -a; . /etc/setka/setka.env; set +a; cd /home/valstan/SETKA && exec ./venv/bin/python …'`.
- **PowerShell 5.1 портит кавычки в аргументах `ssh`** — всё сложное через файл-обёртку на `/tmp`
  (или base64).
- **`run_script` во встроенном браузере** — выполняется, но **вывода не возвращает**. Опции
  выпадающих списков ВК внутри iframe не индексируются — клик по координате из скриншота.
- **Юниты прод-сервисов называются `setka-*`** (`setka-celery-worker`, `setka-celery-beat`,
  `setka-vk-bot`, `setka-radar-intake`), а не `celery-worker`/`vk-bot`: `systemctl is-active
  celery-worker` отвечает `inactive` и выглядит как падение. Health — `curl
  http://127.0.0.1:8000/api/health/full`.
- **Счёт районов Татарстана по базе против Википедии** — сходится только с поправкой на
  упразднённые: код `bal` — это **Балтасинский** (Балтаси), а не Балтинский.

## Failed approaches этой нитки

- **Параллельные сабмиты тяжёлых пачек** (из прошлого handoff, подтверждено): только последовательно.
- **Воркер упал по rate limit провайдера** (batch2 марафона 09.10): лечится перезапуском воркера, данные fetch на месте. Не путать с ошибкой разбора.
- **Транслит в хотлайн** (07.10): первое сообщение ушло транслитом из страха кракозябр — проверка показала, UTF-8 идёт чисто; переотправил по-русски. Правило: после `send` перечитывать ленту глазами (уже в спеке).
- **«25 прогонов в день»** — неверная рамка владельцу: 3–4 марафона покрывают флоу, т.к. повторные заборы тянут следующие без вердикта. Не повторять арифметику стока для флоу.
- **Очередь — флоу, не сток** (замер 08.10): total kept-без-вердикта — архив аудита (тысячи), живая очередь — fresh 24ч (~3200/сутки по сети). Условие «очередь не убывает» бьёт мимо; остановка марафонов — по усталости.

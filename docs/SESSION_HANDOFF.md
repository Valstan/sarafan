## Failed approaches (этой нитки)

- **Ротировать индекс PENDING переносом открытых записей в `CLOSED.md`** — не
  работает семантически: `CLOSED.md` — это «закрытые записи», а открытых среди
  86 не было. Рабочая дорога — **состояние из индекса в тела**, а в индексе
  остаётся только тег старения.
- **Считать состояние дубликатом по совпадению СЛОВ** между индексом и телом —
  ложно: у 9 из 21 записей совпадение было только по словам, а дословно состояния
  в теле не было. Признак дубликата — **дословное** вхождение, иначе состояние
  переносится в тело.
- **Пересобрать строки индекса без префикса `pending/` в ссылке** — гейт это
  пропускает (он принимает обе формы), поймал только отдельный аудит ссылок:
  ссылки в индексе надо пересобирать **как были**. Урок: гейт проверяет
  существование, а не форму — форму надо проверять отдельно.
- **Гонять SQL и awk на боксе одной SSH-строкой с кавычками** — PowerShell съедает
  кавычки, удалённый шелл получает команду без них. Рабочие приёмы: паттерны
  **без пробелов** (`2026-11-22.2[12]:.*троттлингом` — точкаmatcher вместо
  пробела) либо `scp` файла + `psql -f` (как в памятке `/sql`).
- **Передать программу inline через base64 в SSH** — гейт инструмента блокирует
  (длинная полезная нагрузка в команде). Рабочий путь: `scp` файла на бокс и
  запуск оттуда.
- **Прогнать `pytest tests/ -q` локально** — падает на импорте (`authlib` не
  установлен на этой машине). Локально проходят только подмножества
  (`tests/test_pending_gate.py tests/test_infra/` — 27 тестов), полный прогон — CI.
- **Ждать срока токена из прошлой сессии** — не работает: аккаунт может смениться
  раньше (23.11 так и вышло: #197 умер в 11:03, а срок 11:23 достался уже не
  работающему аккаунту). Точку брать из `profile.json` живой машины.
- **Верить прибору «на слово»** — прибор ответил «не проверено» при сработавшем
  продлении: он считал вызовы «после истечения» по **текущему** сроку токена, а
  после продления срок в будущем. Правка PR #1227. Урок: прибор, написанный до
  первого срабатывания, не может быть свидетелем этого срабатывания — успешный
  сценарий надо **доиграть в тесте на живых данных**, а не считать «и так ясно».

## Текущая нитка

**Вечером пул MiniMax кончается, и весь трафик классификации уходит платному Дипсику.** Живой факт 17.11 (проба пула в 21:45 MSK): в пуле остался один аккаунт `work id=129` — «сегодня: клетка 3, 400 очков, **статус 3 (исчерпан сегодня)**», новых аккаунтов **Карман не отдаёт** («ручки пула не настроены»), в `exclude` уже 9 мёртвых id (8, 17, 120–122, 125, 127–129). Движок молчит 2 422 с (≈40 мин).

Почасовой разрез классификации (МСК, из `logs/neural_usage.jsonl`): **20:00 — Минимакс 41 вызов, Дипсик 0 (0 % платного); с 21:32 — Дипсик 95 вызовов, 1 088 постов, ~1,2 млн токенов (100 % платного).** Причины отказов MiniMax за день: `pool_dead` — 49, `accounts_exhausted` — 43, `karman_unavailable` — 15, `engine_failed` — 6.

Подстраховка работает (решение владельца 17.11, PR #1126): контент не теряется — за день 72 волны ушли «без вердиктов» (144 события skip-wave), и теперь их закрывает Дипсик. **Но платный трафик вырос, и это следствие не работы подстраховки, а пустого пула** — сам по себе фолбэк не починит контур.

Параллельно сделано (всё на GitHub и на проде): единый журнал вызовов нейросетей `modules/neural_usage.py` (одна строка JSON на вызов: движок · поток · когда · объём · исход), панель «Движок классификации» переведена на **московские календарные сутки** (плавающих 24 ч больше нет) и показывает **все потоки** нейросети (классификация, переписывание, сборник, конвейер, уведомления, дистилляция, подбор сообществ) + сколько платных вызовов ушло сегодня.

## Следующий шаг

1. **Решение владельца по потолку платных вызовов.** `CLASSIFIER_PAID_DAILY_CALLS` по умолчанию **0 = без лимита** (как и просили). Ненулевое значение ограничит платный трафик в сутки; после исчерпания чанки пойдут без вердикта. Правка — env на проде, деплой не нужен.
2. **Карману нужен ответ** (письмо от 15.11 без ответа): аккаунты с незабранной клеткой и рабочие ручки пула. Пока пул пуст, вечером весь трафик платный — см. `docs/pending/P227-minimax-kontur-pul-ak-kuntov-avtochekin.md`.
3. **Письмо мозга от 17.11** (радарные пункты P052, P222, P037, P024) — ждёт «ок» владельца на формулировки ответа; сам ответ готовится по индексу PENDING.

Промах 06.11 случился **до** его появления в git (PR #1023, `a5d48d8`, 06.11 10:13 — через 3,5 часа после промаха). **Не дублировать 17б.**
- **«Дистилляция корпуса из 16 коррекций»** — новых правил не дала: корпус уже разобран 06.11 в правило 17. Внесена только правка выученного id 25 (конфликт слоёв «погода»).
- **«Платный фолбэк без видимости»** — 16.11: 47 % трафика на платном движке, и это выглядело как «сбои движка». Причина — пауза 30 мин после трёх пустых аккаунтов. Теперь пауза 10 с и пул мёртвым после 10 подряд, но при лежащем MiniMax платный трафик снова становится 100 % — и без журнала вызовов это не видно. **Не повторять без журнала по потокам.**

   - внести в `vk_tokens` скриптом `/tmp/add_comm_token.py` (`COMM_243526210`, `COMM_243526257`);
   - провалидировать `/tmp/validate_comm_token.py` — тем же хелпером, что и веб-эндпоинт.
2. **Полное оформление** двух групп (full-режим: описание, аватар, обложка, визитка, закреп):
   ```bash
   ssh sarafan "sudo bash -c 'set -a; . /etc/setka/setka.env; set +a; cd /home/valstan/SETKA && exec ./venv/bin/python scripts/setup_groups.py --apply --regions aktanyshsky,yutazinsky'"
   ```
   ⚠️ Не запускать по ним `--repair` **до** `--apply`: repair ставит аватар user-токеном, после чего
   группа перестаёт быть «голой» и full-режим (`--apply`) больше не сработает — описание и обложка

## Failed approaches (этой нитки)

- **`groups.edit` через API — `[3] Unknown method passed`** на 5.103/5.131/5.199 и через `vk_api`, и
  сырым HTTP, **если токен пользовательский**. Community-ключом работают `description` и `city`.
  Значит: **город и описание ставятся скриптом**, а `screen_name` (короткий адрес) — наоборот,
  только user-токеном ⇒ **короткий адрес только руками в браузере**.
- **Короткий адрес у `leninogorsky` / `bugulminsky`** — activity «Публичная страница», «Тематика»
  пустая, ВК отклоняет сохранение целого блока «Основная информация». Обход только один —
  пересоздать группу с тематикой «Городское сообщество».
- **`--repair` до `--apply`** по новым группам — repair ставит аватар user-токеном и группа перестаёт
  быть «голой», после чего full-режим `--apply` больше не срабатывает.
- **Стена/предложка — не через «Контент» → «Посты» → «Настроить»**: клик попадает в переключатель
  показа раздела и **выключает** его. Рабочий путь — старая страница `?act=sections` (строки «Стена»
  и «Предлагаемые новости» + своя кнопка «Сохранить»).
- **`sudo bash <скрипт>` на проде** — хост-гейт режет форму («cannot prompt for permission»),
  а `sudo -u postgres psql -d setka -f file.sql` — проходит. Проверять форму команды, а не права.
- **PowerShell 5.1 портит кавычки в аргументах `ssh`** — `-c "SELECT …"` доходит до bash без кавычек.
  Рабочие формы: `psql -f file.sql` и короткие команды без кавычек; всё сложное — через файл-обёртку.
- **`run_script` во встроенном браузере** — выполняется, но **вывода не возвращает**. Опции
  выпадающих списков ВК внутри iframe не индексируются — клик по координате из скриншота.
- **Опции списка городов** не индексируются; кириллица в селектор города через `type`/`fill` не
  вводится — город ставится скриптом, а не руками.
- **Счёт районов Татарстана по базе против Википедии** — сходится только с поправкой на
  упразднённые: код `bal` — это **Балтасинский** (Балтаси), а не Балтинский. Смотреть `regions.name`.

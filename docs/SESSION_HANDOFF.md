## Failed approaches (этой нитки)

- **Тематика/адрес Муслюмовского из UI и API** — не ставятся: у группы-публичной
  страницы список тематик из 2 пунктов, `groups.edit` параметр `activity` игнорирует,
  `screen_name` требует user-токен, сохранение блока «Основная информация»
  отклоняется плашкой «Укажите тематику сообщества». Тематика задаётся **только в
  диалоге создания группы**. **Не повторять** без новой информации: скорее пересоздать
  группу, чем ловить ту же плашку.
- **Строгое равенство `via == "community-token"`** в метке `on_wall` — метка бывает
  и `community-token:<NAME>` (перебор кандидатов, `_try_community_candidates`), то
  есть весь кандидатный прод-путь молча выпадал бы из журнала. Сверка **по префиксу**.
- **`headers={}` в каждом вызове** (`_prepare`) — ломает заглушки с фиксированной
  сигнатурой (`fake_post(url, json=None, timeout=None)`). Ключ добавляется только
  если есть что положить.
- **Файл `docs/pending/P215-…`** не открывался инструментом правки: в моих путях
  была опечатка в имени (`publikacij` вместо `publikaciy`). Файл жив и здоров —
  проверять точное имя, а не искать проблему в FS.

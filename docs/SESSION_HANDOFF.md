## Failed approaches этой нитки

- **Параллельные сабмиты тяжёлых пачек.** 4 POSTа разом → read timeout во всех. Сервер при этом записал всё с первой попытки (повтор вернул `skipped_existing` ровно по счёту). Лечится последовательными сабмитами; зафиксировано в `.claude/commands/progon.md`. Не повторять.
- **Review API ключом рутины.** `GET /api/classifier-review/rules` с `X-API-Key` → 404/401: review-роутер на сессионной cookie, не на ключе. Правки правил — SQL-файлом через `/sql` с гейтом. Не повторять.
- **Своя формулировка уронила чужой тест.** Новый пункт упомянул «Разрешённые темы» — упал `test_prompt_without_dictionary_has_no_theme_block`. Тест сторожит поведение, править надо было формулировку (сделано), не тест.
- **IDN с прод-Python.** Кириллический URL → `UnicodeEncodeError: latin-1`; нужен punycode (`'такси.вмалмыже.рф'.encode('idna')`), считается локально.
- **Pre-commit не в PATH PowerShell.** Лечится `venv\Scripts\python.exe -m pre_commit` (из прошлого handoff, снова сработало).

## Failed approaches (этой нитки)

- **Обычный коммит поверх ложного срабатывания `private-key`** — не лечит: `gitleaks detect`
  отвечает на вопрос «есть ли секрет в истории», а срабатывание привязано к коммиту `4c02f84`,
  который остаётся достижимым. Лечится **пересборкой ветки одним коммитом** (`--amend` +
  `--force-with-lease`), грабля — [G297](../brain_matrica/cross-project-ideas/gotchas/G297.md).
  Плюс свойство нашего CI: `fetch-depth: 0` тянет все ветки, поэтому находка в чужой ветке
  красит **любой** PR.
- **Allowlist в `.gitleaks.toml`** — отклонён владельцем: фраза-маркер осталась бы в репозитории
  зачётной дорожкой для настоящего ключа.
- **Параллельный марафон суб-сессиями агента** — free-тир отвечает агенту тем же
  `Free usage limit reached`, что и движку; разбор шёл последовательно в одной сессии.
- **Смёржить #995 как есть после того, как handoff в `main` обновился** — PR становился
  конфликтным. Разрешение: handoff взят из `main` (свежее), из ветки сохранён только
  `docs/SESSION_REPORT_SITES.md`; иначе мёрж откатил бы handoff на версию 30.10.

## Текущая нитка

**P224 — расход DeepSeek.** Три рычага закрыты: правилник сжат (база 12 638 → 8 871 символов, формулировки 34 выученных правил 12 815 → 11 092), крупные чанки внедрены (8 регионов в вызов; живой замер 10.11 в 14:13: 200 постов → **8 вызовов**, 137 002 токена против 507 480 раньше). Третий рычаг — **мост к локальному движку**: построен, измерен и в бою.

**Движок и где он живёт.** Локальной llama-модели нет ни на ПК, ни на боксе; есть **OpenCode v2.1.4** с free-тиром (`opencode/deepseek-v4.1-flash-free`, цепочка фолбэка из трёх моделей) — это **не локальная модель, а облако под флажком**: деньги DeepSeek не тратятся, но лимиты и гейты реальны. По решению владельца движок перенесён **на бокс**: `opencode serve --service` под systemd-юнитом `opencode-engine` (обёртка сторожит порт), демон — **кроной раз в 5 минут**, локально (`--local`, без SSH). Ключ на сервер не переносился (free-тир отдаётся с публичным ключом). Free-тир **ответил с IP бокса** — гейта по IP нет (ADR-0014: тогда он закрывал весь каталог).

**Замер (теневая сверка, 120 постов золотой выборки, один и тот же промпт у обоих движков):** action — облако 80,8 % → локальная 82,4 % (108 постов, 1 отказ); парная статистика: прав только облако 6, прав только локальная 10. **Паритет**, проба мозга (18,2 %) на наших постах не подтвердилась.

## Failed approaches (этой нитки)

- **Локальная llama-модель на ПК** — весов и рантайма нет; exo на этом CPU даёт 0,6B ≈ 8 ток/с, а наш промпт — 9K токенов, то есть минуты на чанк. **Не повторять** без машины с GPU в кластере exo (тогда exo переключается на CUDA/vLLM).
- **Free-тир на большом чанке (8 регионов, до 40 постов)** — модель уходит в рассуждение и молчит (чанк из 23 постов — 11 минут). Отсюда `--regions-per-chunk 2` и потолок на одну модель (`--model-timeout`).
- **Inline-JS в шаблоне панели** — блока `scripts` в `base.html` нет (там `extra_scripts`), а битая тернарная операция дала `SyntaxError`; страница выглядела «просто пустой». JS вынесен в `web/static/js/local_engine.js`, синтаксис проверяет `node --check` в CI.
- **`date_trunc` с биндом в GROUP BY** — Postgres не узнаёт выражение (500 на API панели); единица усечения теперь литерал.
- **gitleaks `curl-auth-user`** — ложное срабатывание на `-u "user:$(...)"` в README; строка переписана через netrc, а история ветки пересобрана, чтобы находка не висела в git.

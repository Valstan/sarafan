## Failed approaches (этой нитки)

- **`groups.edit` через API — `[3] Unknown method passed` на 5.103/5.131/5.199**, если токен
  **пользовательский**. Community-ключом работают и `description`, и `city`. Значит: описание и
  город ставятся скриптом, а `screen_name` — наоборот, только user-токеном ⇒ **короткий адрес
  только руками в браузере**.
- **`groups.edit` ждёт параметр `city` (строка), а не `city_id`.** С `city_id` вызов проходит без
  ошибки, а город **не меняется** — молчаливый no-op. Проверять чтением `groups.getById(fields="city")`
  сразу после записи.
- **Значение ключа читать из DOM, а не из `inspect`.** `inspect` отдаёт текст поля обрезанным (100
  символов), и такой токен уходит в БД битым: `[5] User authorization failed: invalid access_token`.
  Рабочий путь — `query(kind="dom", selector='input[value*="vk1"]')`: там `value` целиком (220).
- **Передача файла на прод — через base64, а не конвейером PowerShell.** `Get-Content -Raw | ssh`
  дописывает `\r\n`: токен приезжал длиной 222 вместо 220 и не проходил валидацию. Надёжно —
  `[Convert]::ToBase64String(...)` + `printf %s <base64> | base64 -d`.
- **Push-подтверждение ВК живёт около 10 минут.** Два запроса подряд (в разных вкладках)
  истекают молча — страница просто возвращается к пустому списку ключей. Рабочий режим: **один
  ключ за раз**, значение читать сразу после подтверждения.
- **Страница «Не пришло уведомление?» открывается сама**, когда push-окно истекло: там есть
  повторный запрос push и запасной канал **SMS**. Радио «Samsung SM-A225F» выбрано по умолчанию.
- **Короткий адрес у `leninogorsky` / `bugulminsky`** — activity «Публичная страница», «Тематика»
  пустая, ВК отклоняет сохранение целого блока «Основная информация». Обход один — пересоздать
  группу с тематикой «Городское сообщество».
- **`--repair` до `--apply` по новым группам** — repair ставит аватар user-токеном, группа
  перестаёт быть «голой», и full-режим `--apply` больше не срабатывает.
- **Стена/предложка — не через «Контент» → «Посты» → «Настроить»**: клик попадает в
  переключатель показа раздела и **выключает** его. Рабочий путь — `?act=sections`.
- **`sudo bash <скрипт>` на проде** — хост-гейт режет форму; работает
  `sudo bash -c 'set -a; . /etc/setka/setka.env; set +a; cd /home/valstan/SETKA && exec ./venv/bin/python …'`.
- **PowerShell 5.1 портит кавычки в аргументах `ssh`** — всё сложное через файл-обёртку на `/tmp`.
- **`run_script` во встроенном браузере** — выполняется, но **вывода не возвращает**. Опции
  выпадающих списков ВК внутри iframe не индексируются — клик по координате из скриншота.
- **Счёт районов Татарстана по базе против Википедии** — сходится только с поправкой на
  упразднённые: код `bal` — это **Балтасинский** (Балтаси), а не Балтинский.

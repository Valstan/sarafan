## Failed approaches (этой нитки)

- **Пайп ssh-вывода в файл (`| Out-File`)** — PowerShell ждёт выхода ssh,
  teardown висит, файл пуст. **Правило:** `Start-Process -RedirectStandardOutput`
  + `Wait-Process -Timeout` + `Kill` (отправлено мозгу дополнением к G455).
- **Многострочник через `bash -s` по stdin** — PowerShell отдаёт CRLF,
  bash давится (`$'{\r'`). **Правило:** только однострочные ssh-команды;
  сложное — по одному вызову на операцию.
- **`wall.edit` для старых визиток** — VK: `edit time expired` (7 суток).
  Только перевыпуск (удалить + опубликовать + закрепить). Community-токен
  `wall.*` не умеет вовсе (error 27) — чтение/запись стен только user-токеном.
- **Стена kaybitsky `wall=1`** — вопреки предположению правится через API
  (`groups.edit wall=2` сработал, сверено чтением). Не объявлять «только
  браузер» без пробы.
- **Карты вердиктов править edit-латками** — вслепую бьёт по соседним записям
  (дважды чинил следы). **Правило:** после каждой правки — машинная сверка
  1:1 скриптом до отправки.

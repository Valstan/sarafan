## Failed approaches (этой нитки)

- 🔴 **Локальный temp — не источник истины.** Scratch-файлы захода исчезли из temp-каталога, хотя все шаги отчитались успехом. Перепроверил пулы из БД поименно + `git log` — сошлось. Промежуточные выборки держать до конца захода и чистить самому.
- 🟡 **Арифметика в журнале — только из сверки.** «Оричи 21→33» при сиде +13 — поймано боевой сверкой (в БД 34), починено.
- 🟡 **`groups.create` недоступен нашим токенам** — группы создаёт владелец руками.
- 🟡 **Smoke `would_publish=None` — не регресс, а штатный skip-wave.** Dry-run возвращается до `_save_stats`; волна без вердиктов возвращает dict без ключей результата. Проверяется логом отбора, а не цифрами smoke.

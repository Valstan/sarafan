## Failed approaches (этой нитки)

- **Параллельный разбор батчей суб-сессиями MiniMax** — то же, что с free-тиром OpenCode: воркеры
  умерли на `insufficient balance (1008)`, не отдав ни одного вердикта. Вывод для планирования:
  free-тир/баланс упирается на числе **одновременных** агентов, а не только на их числе.
- **PowerShell-редирект в файл** — `>` пишет UTF-16LE, а `Out-File -Encoding utf8` — с BOM.
  Отсюда два сбоя: commit-msg хук отверг сообщение как «не Conventional Commits» (BOM в первой
  строке), и забор `/postulates` весил вдвое больше ожидаемого. Любой вывод в файл — только
  `[System.IO.File]::WriteAllText(path, text, (New-Object System.Text.UTF8Encoding $false))`.
  Родственник P196 (ssh-редирект): **результат проверять на диске, а не по коду возврата** —
  scp корпуса «упал» по таймауту, хотя файлы доехали.
- **`sudo bash -c 'cd /home/$SUDO_USER/SETKA'`** — `$SUDO_USER` разворачивается во внешней
  (не-sudo) оболочке и даёт `/home//SETKA`; нужен явный путь `/home/valstan/SETKA`.
- **Сравнение файла на проде с локальным через `git diff --no-index`** — показало пусто, и это
  верно: SHA256 различается (CRLF против LF), содержимое идентично. Расхождение хэшей про кросс-платформу
  — не про изменение кода.
- **Забор корпуса дистилляции окном 10 дней** — счётчик панели дал 13 коррекций на 6 постов;
  остальные 8 решений журнала в таблицу `corrections` не попадают (они применены через `finalize`).
  Корпус дистилляции — это панель **плюс** журнал, не только панель.

## Failed approaches (этой нитки)

- 🔴 **Ждать «все чеки» вместо обязательной.** Не повторять: гейт main — ровно `test (3.12)`.
- 🔴 **Snapshot/reфы для ВК-автоматизации.** Accessibility-дерево нового VKUI почти пустое;
  форма создания живёт в кросс-доменном iframe `static.vk.ru/community_create` — работать
  только через `evaluate` с `frameID`. **Не повторять** попытки через `click`/`fill` по рефам.
- 🔴 **Быстрые клики подряд по модалке создания.** Сплэш открывается и тут же закрывается
  от следующего клика. Протокол: один клик → пауза → пассивный рид (скриншот). **Не повторять** очереди кликов.
- 🔴 **Программный ввод в поле адреса.** Синтетический `input`-ивент проверку занятости
  не запускает. Работает: синтетический bulk + пара настоящих клавиш (`press` Backspace +
  последний символ). Факт — только по URL (`vk.ru/<адрес>?act=edit`).
- 🔴 **Сохранение до подсказки «свободен».** Адрес молча не принимается, остальное
  сохраняется — выглядит как успех. Сначала дождаться подсказки, сохранять сразу после неё.
- 🔴 **`?act=edit` напрямую после серии навигаций.** Рендерится скелетом и не оживает
  (ни reload, ни новая вкладка). Лечится заходом через главную группы → `/settings`.
- 🔴 **`groups.edit` через API для адресов.** Мёртв (`[3] Unknown method passed` тем же
  токеном, что льёт обложки) — адреса только браузером. Подтверждено второй раз (первый — P170).
- 🔴 **Автокомплит города при дохлой сети.** Подсказки не грузятся — ставить ID города
  напрямую в `#sel_groups_edit_city` (Камское Устье 11567, Большие Кайбицы 1095854 —
  не путать с 1095234 Кайбицы Буинского района, Чистополь 5103).
- 🔴 **Сохранение города сносит описание.** У Камского Устья описание стало 0 зн. —
  восстановлено `--refresh-desc --apply`. После любых сохранений сверять через API
  (`groups.getById fields=city,description`), а не по URL.

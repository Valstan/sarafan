## Failed approaches (этой нитки)

- **`groups.edit` через API — `[3] Unknown method passed` на `v=5.199`** (проверено 20.11 на
  пользовательском токене): и `city`, и `screen_name` так не ставятся. Город и короткий адрес —
  только руками в настройках. В плане порции не закладывать API-путь.
- **`sudo bash <скрипт>` на проде** — хост-гейт блокирует («cannot prompt for permission»),
  хотя `sudo -u postgres psql -d setka -f file.sql` проходит. Форма команды важнее прав.
- **Запись прод-данных мимо гейта #025** — не пробовать: гейт существует именно для этого,
  а «инструмент опроса недоступен» — не повод писать `UPDATE` без подтверждения.
- **`ctrl+a` в поле короткого адреса** — не сработал, значение дописалось к дефолту
  `club243526155` («Как правильно выбрать адрес…» вместо «Адрес свободен»). Рабочий путь —
  `fill` (чистит поле), затем ждать подсказку ~5 с и только потом «Сохранить».
- **`run_script` во встроенном браузере** — выполняется, но **вывода не возвращает**; читать
  DOM через него бесполезно. Опции выпадающих списков внутри iframe не индексируются
  (`ref` не выдаётся) — клик по координате из скриншота + проверка скриншотом.
- **PowerShell 5.1 портит кавычки в аргументах `ssh`** — `-c "SELECT …"` доходит до bash без
  кавычек. Рабочие формы: `psql -f file.sql` и короткие команды без кавычек; всё сложное —
  через файл-обёртку на `/tmp`.
- **Счёт районов Татарстана по базе против Википедии** — сходится только с поправкой на
  упразднённые: код `bal` — это **Балтасинский** (Балтаси), а не Балтинский (его в списке 43
  уже нет). Смотреть `regions.name`, а не код.

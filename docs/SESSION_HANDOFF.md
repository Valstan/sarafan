## Failed approaches этой нитки

- **`sudo` + `~/SETKA` → `/root/SETKA`.** Под sudo `~` — рутовый: только
  абсолютный `/home/valstan/SETKA` (рецепт в `discover_communities.md` молчит —
  не повторять вслепую).
- **Standalone-скрипт к classifier-сервису без импорта моделей** → mapper
  `Region` не находится (`KeyError: 'Region'`). До обращения к `rules`
  импортить `database.models` + `models_extended` (как `init_db`).
- **SSH-teardown hang** — вывод полный, а exit висит (`GetConsoleMode`,
  tool-timeout после вывода; письмо в мозг 2026-10-10). Не чейнить команды
  после ssh через `;` — не выполнятся; одна удалённая операция на вызов;
  успех — по выводу/маркеру. Параллельные ssh-батчи тем более нельзя.
- **PowerShell 5.1:** нет `&&`, `head`/`tail`/`grep` (разделитель `;`,
  `Select-Object -Last`, `Select-String`); смешанные слеши в путях scp терпит.
- **Submit пачками строго последовательно** в одном вызове (параллельные POST
  роняют чтение ответов — требование скилла, соблюдено).

## Failed approaches (этой нитки)

- **Аккаунт-ключ для free-tier** — 403 не снимает (ключ открывает только платные модели). Не повторять.
- **WARP на боксе** — пакет ставится, регистрация невозможна: TLS ClientHello к API WARP гасится (DPI по SNI; `openssl s_client` воспроизводит). Установка откачена полностью. **Не повторять** без новой информации; вариант «WARP внутри донорского VPS» — отдельная работа (владелец).
- **`systemd-run --setenv CLASSIFIER_ENGINE=opencode`** — `EnvironmentFile` перебивает; подмена должна жить в процессе (`/bin/bash -c 'export …; exec …'`) или в env-файле.
- **Смена payload/пермишенов под Zen** (none/base12/full14 × разные модели) — 403 одинаковый: гейт не по payload.
- **Прямой HTTPS к API Zen** — free-tier только «изнутри» (ADR-0007, подтверждено 18.10).

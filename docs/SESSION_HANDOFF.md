## Failed approaches (этой нитки)

- 🔴 **Самоссылка в `neighbors` невидима для проверки симметричности** — код симметричен сам с собой по построению. Три проверки (симметрия / самоссылки / висящие коды), а не одна; все три — в комментарии миграций 109/110.
- 🔴 **`dmesg -T` врёт на ~45 минут.** OOM «в будущем» оказался событием получасовой давности; надёжная цифра — монотонные часы (`[3898837]` при uptime 3897045). Плюс фильтр `oom-kill` не матчит `OOM killed process` — второй прогон сказал «ноль событий», которых было 26.
- 🔴 **`transferSize === 0` в `performance.getEntriesByType` — не признак ошибки** у кросс-доменных ресурсов без `Timing-Allow-Origin` (как и `responseStatus === 0`). Правильный признак — только ошибки консоли. Первый чек «155 ресурсов упали» был неверным и отозван.
- 🟡 **Кнопка «Создать сообщество» звала `window.showWiki`, которой не было** — чанк не догрузился через прокси (`st*.vk.ru` чередовались). Группы в итоге созданы владельцем вручную; `groups.create` нашим токенам недоступен (`Unknown method passed`).
- 🟡 **Сидер молча пропускает дубликат по (vk_id, category) включая `is_active=false`** — Ухтым ППМИ «already present», хотя в активном пуле его нет. Проверять неактивные строки перед выводом «взято N».
- 🟡 **Ручной `groups.getById` батчем (до 500 id) + `wall.get` точечно** — дешёвый способ разрулить омонимы (city/country/decisive), когда описания нет, а постов в скане нет (вне топ-70).

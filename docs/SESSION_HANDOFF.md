## Failed approaches (этой нитки)

- **Цепочка `$(ssh … '…')` + python в одной команде PowerShell 5.1** — ssh
  выполняет команду, отдаёт весь вывод, но teardown висит (~14 мин): batch2/3
  не собрались, команда вся умерла по таймауту. **Правило:** одна удалённая
  операция на вызов; забор ключа и fetch — раздельно; успех — по маркеру
  вывода, не по exit-коду.
- **Суб-сессии-воркеры разбора** — на этой машине вернули болтовню вместо
  работы (дважды, вторая попытка прервана). **Не повторять** здесь; fallback
  по памятке — последовательный разбор в сессии, лимит 8/район.
- **`.git/hooks/pre-commit` с путём другой машины** — в hook был вшит
  `INSTALL_PYTHON='D:\PROGRAMMING\setka\venv\Scripts\python.exe'` (не
  `sarafan`) → коммит молча падал exit 1 без текста. Хуки НЕ переезжают с
  checkout'ом: лечится `python -m pre_commit install` (venv в PATH) +
  `PRE_COMMIT_HOME` в scratchpad.
- **Фоновый `pip install --user`** — завис на teardown того же класса, убит
  принудительно. Pillow и так уже стоит в venv (проверять импортом, не pip).

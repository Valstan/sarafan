# P196 — SSH-канал деградировал: команды без вывода, деплой без верификации невозможен

**Приоритет:** 🟡 (деплой #895+#896 отложен; прод не тронут, ничего не сломано)
**Создано:** 2026-10-15
**Теги:** `⏱ 2026-10-15 · snooze 0 · fresh`

## Симптом

Ночь 14→15.10, сессия деплоя #896: сначала классический G455-teardown
(вывод приходил, сессия не закрывалась — работали «по маркеру»), затем команды
перестали возвращать вывод вообще — даже `ps` и `git log`. Сработал один раз
голый `echo ALIVE` (канал жив), всё остальное — тишина до таймаута клиента.

## Что известно

- Прод НЕ тронут: все команды сессии были read-only; `git pull`/`restart`
  не выполнялись. Откат не нужен.
- G455 у мозга — про teardown-hang Windows-агента; это хуже: ноль вывода.
- Гипотеза (НЕ проверена): копятся orphan-процессы от сессий, убитых по
  клиентскому таймауту, — каждая оборванная сессия оставляет висящий sshd/git.

## Что проверить (с терминала владельца, без агента)

1. `ps -eo pid,etime,cmd | grep -E 'ssh|git'` — есть ли пачка висящих с
   большим etime; если да — прибить, сверить с G455 (добить строкой мозгу).
2. `uptime`, `free -m` — не под нагрузкой ли бокс (харнесс классификатора,
   свежий деплой #894).
3. Один короткий `git -C ~/SETKA log --oneline -1` — вывод вернулся сразу?

## Условие снятия

Канал даёт вывод стабильно → деплой #895+#896 по памятке `reliz`
(pull 2 коммитов, restart только `setka`, health-poll, `curl -I` статики).
Если тишина воспроизводится с терминала владельца — это письмо мозгу
(расширение G455), а не молчание.

## Ход 15.10 (сессия opencode, см. handoff 15.10)

- Гипотеза orphan-sshd **опровергнута**: на боксе только listener + текущая
  root-сессия, нагрузка 0.10, память в норме. Корень — связка: немой middlebox
  (TCP established, баннера нет, в журнале sshd попыток нет — флэпает) +
  G455-teardown-hang (команда выполняется, exit висит; успех по маркеру).
- Владелец подправил сеть — интерактивный root ходит. Мой канал работает через
  файловый редирект stdout + kill (сериализация, G454; чейнить после ssh нельзя).
- Попутно вскрыт дрейф ключа комнаты vs файл → **P197**. P196 снимается, когда:
  канал стабилен из моей сессии + марафон идёт штатно.

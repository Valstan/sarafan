## Отбор тройки (канон связности)

Границы сверены 06.11 по ru.wikipedia. Из восьми неразобранных районов Татарстана взяты
три, образующие **замкнутый треугольник** — каждая пара смежна, поэтому соседский обмен
новостями (`share_neighbor_news`) заработает внутри группы сразу.

| Код | Район | Адм. центр | Живых рёбер | Соседи внутри порции |
|---|---|---|---|---|
| `sarmanovsky` | Сармановский | с. Сарманово | 3 (Азнакаевский, Альметьевский, Заинский) | Муслюмовский, Мензелинский |
| `muslyumovsky` | Муслюмовский | с. Муслюмово | 1 (Азнакаевский) | Сармановский, Мензелинский |
| `menzelinsky` | Мензелинский | г. Мензелинск | 0 | Сармановский, Муслюмовский |

Итого 4 живых ребра + 3 внутренних = 7 рёбер — максимум среди связных троек из
неразобранных восьми (Агрызский, Актанышский, Бавлинский, Дрожжановский, Ютазинский;
Тукаевский сознательно пропущен).

## Уроки и тупики

* `groups.create` / `groups.edit` через API **не проходят**: у токена `VALSTAN` в
  `vk_tokens` scope только `wall.read` и `groups.read` (ошибка 3 «Unknown method passed»).
  Переменная окружения `VK_TOKEN_VALSTAN` в `/etc/setka/setka.env` — **мёртвая** (ошибка 5,
  просрочена 12.10); живой пользовательский токен лежит в таблице `vk_tokens`
  (`name='VALSTAN'`, id=4) и годится для чтения. Токен `MAMA` (id=13) тоже жив.
  Починка env-переменной — отдельная задача.
* Создание группы через UI: поля «Название» и «Тематика» в модалке, тематику выбирать
  обязательно — без неё группа выходит «Публичной страницей» с закрытой стеной.
* `groups.getById` отдаёт `activity`, `wall`, `age_limits`, `city` — сверять настройки
  группы дешевле, чем по скриншотам.

# P220 — Татарстан, двенадцатая порция: Сармановский, Муслюмовский, Мензелинский

**Статус:** частично закрыта. Скелет + пулы — на проде, два района активированы, третий ждёт
починки группы ВК. Заказ владельца 2026-11-06: «давай активируем ещё три новых района в
Татарстане».

## Отбор тройки (канон связности)

Границы сверены 06.11 по ru.wikipedia. Из восьми неразобранных районов Татарстана взяты
три, образующие **замкнутый треугольник** — каждая пара смежна, поэтому соседский обмен
новостями (`share_neighbor_news`) заработает внутри группы сразу.

| Код | Район | Адм. центр | Живых рёбер | Соседи внутри порции |
|---|---|---|---|---|
| `sarmanovsky` | Сармановский | с. Сарманово | 3 (Азнакаевский, Альметьевский, Заинский) | Муслюмовский, Мензелинский |
| `muslyumovsky` | Муслюмовский | с. Муслюмово | 1 (Азнакаевский) | Сармановский, Мензелинский |
| `menzelinsky` | Мензелинский | г. Мензелинск | 0 | Сармановский, Муслюмовский |

Итого 4 живых ребра + 3 внутренних = 7 рёбер — максимум среди связных троек из
неразобранных восьми (Агрызский, Актанышский, Бавлинский, Дрожжановский, Ютазинский;
Тукаевский сознательно пропущен).

## Что не сделано и почему

* **Муслюмовский не активирован.** Группа `-243017289` создана, но VK отдала её как
  «Публичная страница» с **закрытой стеной** (`wall=1`): посты видны только подписчикам,
  а подписчиков нет — район выглядел бы мёртвым (урок P193). Форма настроек отказывалась
  сохранять: «Укажите тематику сообщества». Восстанавливать — заполнить activity
  «Городское сообщество» в настройках группы (список тематик алфавитный, «Г» искать
  прокруткой), затем дописать адрес, описание и город.
* **Адрес/описание/город не записались у двух групп.** У Сармановского всё записалось
  (`sarmanovsky_info16`, город Сарманово, описание 421 знак). У Мензелинского и
  Муслюмовского форма показывает введённые значения, но «Сохранить» их не применяет —
  та же блокировка по тематике. Короткие адреса, которые не переименовываются API
  (P121), для них остались дефолтными `club243018412` / `club243017289`; их нужно
  проставить вручную: `menzelinsk_info16`, `muslyumovsky_info16`.

## За владельцем

1. **COMM-ключи** для трёх групп (`COMM_<id>`) — публикация пока пойдёт каскадом
   МАМА → VALSTAN; предупреждение скрипта активации это подтверждает.
2. **«Сообщения сообщества»** включить (иначе COMM-ключ не пройдёт валидацию) и
   **«Предложка» = Все пользователи** (без неё сеть не сможет предлагать новости).
3. **«Ссылки» / «Разделы»** в группах — по образцу предыдущих порций (тоже владелец).
4. Починка группы Муслюмовского и допис адресов/описаний/городов — следующим шагом.

## Уроки и тупики

* `groups.create` / `groups.edit` через API **не проходят**: у токена `VALSTAN` в
  `vk_tokens` scope только `wall.read` и `groups.read` (ошибка 3 «Unknown method passed»).
  Переменная окружения `VK_TOKEN_VALSTAN` в `/etc/setka/setka.env` — **мёртвая** (ошибка 5,
  просрочена 12.10); живой пользовательский токен лежит в таблице `vk_tokens`
  (`name='VALSTAN'`, id=4) и годится для чтения. Токен `MAMA` (id=13) тоже жив.
  Починка env-переменной — отдельная задача.
* Создание группы через UI: поля «Название» и «Тематика» в модалке, тематику выбирать
  обязательно — без неё группа выходит «Публичной страницей» с закрытой стеной.
* `groups.getById` отдаёт `activity`, `wall`, `age_limits`, `city` — сверять настройки
  группы дешевле, чем по скриншотам.

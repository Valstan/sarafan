# P193 — нема: район постит в основном медиа без текста

Посты nema два разбора подряд приходят почти без текста: 06.10 (pilot_run6)
из 9 постов с текстом 3, 07.10 (марафон batch1) все 6 без текста. Вердиктов
по таким постам нет (правило 7 выученных: вложения нечитаемы без медиа —
delete; читаемые фото/PDF — классифицировать по содержимому).

Что видно: район уходит в тень — лента собирается, а разбирать нечего.
Заборы идут с `--no-media`, поэтому проверить вложения из сессии нельзя.

Следующий ход: прогнать район С медиа (`fetch --region nema` без
`--no-media`) и посмотреть, читаемы ли вложения. Если да — разбирать по
содержимому; если нет (видео/аудио) — зафиксировать как структурное
и закрыть запись.

Связь: отчёт марафона 07.10 (сессия), правило 7 выученных.

## Проверка 07.10 (pilot_run8, fetch nema С медиа, limit 10)

- Очередь на 07.10 ~12:45: **9/10 постов С текстом** — паттерн 06–07.10
  (6/6 без текста) не воспроизвёлся. Похоже, район постит волнами:
  06–07.10 была медиа-волна, сегодня текстовая. Структурной немоты нет.
- Единственный безтекстовый (`179286260_24543`, `published_at`
  2026-10-07T09:21:41) — **фото читаемо**: афиша «СЛУЖБА ПО КОНТРАКТУ»
  от Кировской области (выплаты, льготы, 2 телефона). Скачалось 812 КБ,
  текст на изображении полностью разборчив.
- Вывод по правилу 7: вложения nema читаемы → **разбирать по содержимому**,
  не delete. Вердикт по `179286260_24543` не выносился (проба, не прогон;
  уйдёт в ПРОГОН 08.10 — там же спорный момент: областная кампания
  в районной ленте, тема на усмотрение оператора).
- Статус: паттерн подтверждён частично (медиа-волны бывают), лечится
  практикой (fetch с медиа + глаза), кода не требует. Закрывать после
  2–3 подтверждений читаемости подряд.

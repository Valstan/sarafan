# P193 — нема: район постит в основном медиа без текста

Посты nema два разбора подряд приходят почти без текста: 06.10 (pilot_run6)
из 9 постов с текстом 3, 07.10 (марафон batch1) все 6 без текста. Вердиктов
по таким постам нет (правило 7 выученных: вложения нечитаемы без медиа —
delete; читаемые фото/PDF — классифицировать по содержимому).

Что видно: район уходит в тень — лента собирается, а разбирать нечего.
Заборы идут с `--no-media`, поэтому проверить вложения из сессии нельзя.

Следующий ход: прогнать район С медиа (`fetch --region nema` без
`--no-media`) и посмотреть, читаемы ли вложения. Если да — разбирать по
содержимому; если нет (видео/аудио) — зафиксировать как структурное
и закрыть запись.

Связь: отчёт марафона 07.10 (сессия), правило 7 выученных.

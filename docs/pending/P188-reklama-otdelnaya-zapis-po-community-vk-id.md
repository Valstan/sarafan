Заведено при ре-триаже P023 (30.09): запись обещала отдельную запись по
`community_vk_id` — её в `docs/pending/` нет (grep по пути парсинга даёт 0
совпадений), и за это время вырос второй, более широкий вопрос.

## Два хвоста

1. **Обещанная запись не создана.** P023 (май) договорилась: отслеживать
   риск-повтор рекламного поста по конкретной `community_vk_id`. Запись не
   появилась — то есть риск, который тогда решили «держать в реестре», не
   отслеживается нигде.

2. **Fallback собирает рекламу из всего пула.** В 15 регионах, у которых нет
   своей доски объявлений, рекламная сводка набирается из всего доступного
   пула, потому что `reklama` не исключён из фолбэка. То есть агрегаторные
   чужие объявления попадают в ленту районов, где местной рекламы просто нет.
   Это и есть прямой путь к бану аккаунта-админа, который P023 и описывала.

- Синхронный дедуп по тексту есть в сети, идемпотентность по id — в конвейере.

  вызов**, а не техническая правка.

## Стандарт (предложен мозгу)

`POST /api/ingest/posts` + `X-Gateway-Key` (грант `<SITE>_INGEST_KEY`) +
опц. `X-Publish-Key`; тело `{vkPostId, sourceUrl, title?, text?, section?,
date?, images?, publish?}`; идемпотентность по `vkPostId`; ответ `{id}` +
`warnings`. Эталон — портал (464 delivered). Без ключа публикации — черновики.

# P248 — Резервный публикатор мёртв: `VK_TOKEN_VALSTAN` отдаёт `invalid access_token`

**Приоритет:** 🟡 техдолг
**Открыто:** 2026-11-26 · `⏱ 2026-11-26 · snooze 0 · fresh`

## Симптом

`VK_TOKEN_VALSTAN` не проходит проверку: VK отвечает
`error_code=5, User authorization failed: invalid access_token (4)`.
Проверено **и с боевого бокса, и с локальной машины** — токен мёртв
везде, дело не в адресе.

## Что это значит

* `VK_TOKEN_VALSTAN` — **резервный** публикатор (`VK_RESERVE_PUBLISH_TOKEN_NAMES="VALSTAN"`),
  последний рубеж, когда community-токен целевой группы недоступен.
* Основной путь публикации — community-токен каждой группы; он лежит в БД
  (`vk_tokens`, 90 записей) и **работает**: с домашнего адреса VK принял
  выборочную проверку community-токенов 26.11.
* То есть публикация сегодня работает, но **резервного публикатора нет**:
  если у группы отвалится community-токен, волна встанет вместо того, чтобы
  уйти на резерв.

## Смежный факт

Основной публикатор по конфигурации — `MAMA`
(`VK_PUBLISH_TOKEN_NAME="MAMA"`), но **токена `VK_TOKEN_MAMA` нет ни в
комнате КАРМАНА, ни в env-файле бокса**: публиковать приходится
community-токенами. Имя `MAMA` в whitelist сейчас указывает в пустоту.

Публикационный user-токен `VK_TOKEN_VITA` жив (VK его принимает), но он в
жёстком deny-list (`VK_NEVER_PUBLISH_TOKEN_NAMES="VITA"`) — по решению
владельца.

## Что нужно от владельца

Ротация токена — гейт #025 (прод-операция, действие с доступом к аккаунту),
поэтому автоматически не делается. Либо решение «оставить как есть» — тогда
в записи остаётся явный факт: **резервного публикатора нет**.

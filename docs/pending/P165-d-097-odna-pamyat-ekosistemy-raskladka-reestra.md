## Ротация 23.11.2026 — условие расконсервации наступило

Условие записи было — «перерастёт потолок — переложить по индекс+файл». 23.11 индекс
дошёл до **50 961 Б при потолке гейта 51 200 Б**: следующая же строка его ломала, а
значит ломала гейт pre-commit и **весь** поток PR'ов. Записано было 86 открытых
записей, и **закрытых среди них не было** — унести в историю было нечего, поэтому
ротация пошла по другой дороге: **состояние уехало из индекса в тела**.

| Что | Было | Стало |
|---|---|---|
| Живой индекс | 50 961 Б | **29 781 Б** (запас 21 419 Б) |
| Состояние в строках индекса | ≈20,5 КБ (86 записей) | **0** — в индексе только тег старения |
| Тела записей | без состояния | 74 записи получили секцию `## Состояние на 23.11.2026 (перенесено из индекса при ротации)` |
| Гейт | 235 записей / 235 строк | без изменений: **235 / 235**, exit 0 |

**Почему состояние не выкинуто, а перенесено.** У 74 записей подробности индекса были
**единственным** местом, где они записаны именно так: тело пересказывало их своими
словами. Поэтому совпадения «по словам» для признака дубликата **не хватило** — 9
записей прошли проверку по словам, но дословно их состояния в теле не было; они тоже
перенесены. Дословно совпавшие 12 — это и есть настоящие дубликаты: состояние в теле
уже было, вторая копия не заводилась (канон: два места с одним и тем же содержимым
сливаются в одно).

**Что теперь в индексе.** Строка = номер · заголовок-симптом · ссылка · тег старения
(`⏱ дата · snooze N · статус`). Тег остался в индексе намеренно: по нему `/start`
находит протухшие пункты, **не открывая тело** ([`/start`](../../.claude/commands/start.md)
§2.1) — для этого правило старения и сделано.

**Проверка, что ничего не пропало.** Сверка исходного индекса (из git) с телами после
ротации: 86 состояний, **0 потеряно** — каждое найдено в теле дословно. Гейт
[`scripts/pending_gate.py`](../../scripts/pending_gate.py) — exit 0, 235/235.

## Открытый остаток

1. **`AGENTS.md` — 75 КБ (замер 23.11) и читается целиком** каждой сессией (`CLAUDE.md`: «перед любым действием
   полностью прочитай»). Это единственный наш файл > 50 КБ, который читается целиком: остальные
   крупные (`REGION_REFRESH_LOG.md` 104 КБ, `docs/ops/region-activation-checklist.md` 78 КБ)
   открываются точечно, читать их целиком никто не велит.
   **Пока не режем:** ADR-0013 §2 у самого мозга оставляет канон в Tier-1 как читаемый целиком,
   и канон — не реестр записей, а связный свод правил; раскладка по файлам разорвала бы его
   логику ради экономии, которой не просили. **Триггер к пересмотру:** канон перевалит 100 КБ
   либо на старте появится вторая обязательная к чтению целиком простыня.
2. **Указатели вместо ссылок.** В живых файлах 55 упоминаний `G<N>` — все указатели по номеру
   (типичная строка ~90 символов: номер + одна поясняющая оговорка), **копий тел записей мозга
   нет**, своего реестра граблей мы не заводили никогда. Но кликабельной ссылкой оформлены
   только 3 из 55. Историю не переписываем; **правило вперёд:** новая ссылка ведёт на файл
   записи (`cross-project-ideas/gotchas/G<N>.md`), а не голым номером.
3. **Отчёт мозгу 02.10** (`ack: report`, три строки) — заведён в [`TICKLER.md`](../TICKLER.md).

## Почему это не «уборка ради уборки»

Реестр на 987 КБ не просто дорог — он **прячет**: промах по запросу стоил десятков килобайт
контекста, поэтому его и не грепали, а читали целиком, то есть платили за всю память каждый раз,
когда нужна была одна запись. После раскладки промах стоит один файл в 2–6 КБ.

# P201 — Free-tier OpenCode закрыт по IP платформы с 17.10: авто-классификацию нечем вернуть

**Приоритет:** 🔴 (блокер классификации; наш код готов и выкачен — открыт внешний гейт)
**Создано:** 2026-10-18
**Теги:** `⏱ 2026-10-18 · snooze 0 · parked · условие: гейт платформы снят (слежение — TICKLER 2026-10-19) ЛИБО владелец даёт платный ключ ЛИБО свой выход (линия P195)`

## Симптом

18.10 живой прогон движка opencode (v2, #910) на прод-данных дошёл до шлюза
и получил 403:

```
{"type":"error","error":{"type":"FreeTierError","message":"OpenCode's free tier can only be used from within OpenCode. ..."}}
```

— одинаково для всех моделей цепочки (longcat-2.5-preview-free, big-pickle,
glm-5.3-flash-free) и всех наборов session-пермишенов (без запретов / базовый /
полный). Наш путь запуска исправен: прогоны доходили до нужного движка и
цепочки (первая попытка маскировалась `--setenv`, перебитым `EnvironmentFile`
— см. Failed approaches в handoff).

## Причина

Платформенный **IP-reputation гейт** (волна ~16–17.10): free-tier разрешён
«из самого OpenCode», а с серверных/датацентровых IP закрыт. Аккаунт-ключ
бесплатный тир **НЕ поднимает** — открывает только платные модели (проверено
18.10). Не наш payload: A/B в апстрим-треде — с residential-IP 403, через
WARP — OK.

Апстрим-инцидент на 18.10 открыт, без ETA:
[#56324](https://github.com/anomalyco/opencode/issues/56324),
[#56397](https://github.com/anomalyco/opencode/issues/56397),
[#56341](https://github.com/anomalyco/opencode/issues/56341),
[#56334](https://github.com/anomalyco/opencode/issues/56334).
Мозг: D-133 (15.10) — вендор уже закрывал бесплатную линию для сторонних
харнессов; волна 17.10 — развитие того же.

## Что пробовали и отвергли (18.10)

- **Аккаунт-ключ на free-tier** — не поднимает (ключ = только платные).
- **WARP на боксе** — пакет ставится, регистрация невозможна: TCP 443 до API
  WARP открыт, но TLS ClientHello к `engage/api.cloudflareclient.com` гасится
  (DPI по SNI; воспроизведено `openssl s_client`). Установка откачена
  полностью. **Не повторять** без новой информации.
- **Прямой API Zen** — free-tier только «изнутри» (ADR-0007).

## Замечания для revival (когда гейт снимется)

- `CLASSIFIER_ENGINE` перебивается `EnvironmentFile` systemd —
  `systemd-run --setenv` не работает; подменять в процессе
  (`/bin/bash -c 'export …; exec …'`) или править env.
- До включения — короткий живой прогон `scripts/opencode_classify_once.py`
  и замер токенов; затем сутки стабильного `/tmp` (условие P200).

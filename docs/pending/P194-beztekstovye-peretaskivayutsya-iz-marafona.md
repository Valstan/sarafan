# P194 — безтекстовые посты перетаскиваются из марафона в марафон

Заборы идут с `--no-media`, поэтому посты без текста вердикта не получают
(памятка, Шаг 2) и возвращаются в каждый следующий забор: марафон 09.10 —
66 безтекстовых из 638, daily-прогоны — 5–9 за раз. Объём забора и разбора
тратится впустую на то, что заведомо не разберётся.

Конфликт правил: выученное 7 требует классифицировать по вложениям, если
читаемы, — но вложений в `--no-media`-заборе нет. P193 доказал, что вложения
читаемы (nema-афиша прочитана глазами 07.10).

Варианты: (а) точечный добор медиа по безтекстовым lip (`fetch` с медиа
только их — нужен фильтр по lip, сейчас его нет); (б) признать постоянный
пропуск и резать безтекстовые из заборов лимитом (экономия объёма, потеря
единичных publish вроде афиш). Решение за владельцем.

Связь: марафон pilot_run11 09.10 (66 без вердикта), P193, правило 7.

## Решение 15.10 (марафон pilot_run4)

Марафон собран **с медиа**: 651 пост, 26 вложений; все 24 безтекстовых поста получили
вердикты по вложениям (`media_summary` заполнен, включая видео-кейс). Выбор владельца —
вариант «читать медиа»; потерянных публикаций нет.

Остаток (dev):

1. `fetch` тянет медиа всего забора, а нужен точечный добор по безтекстовым `lip`
   (фильтра по `lip` в `fetch` нет) — иначе вложения качаются и для текстовых постов.
2. 5 постов b2 (`lip` 40, 66, 133, 136, 164) имели фото в `pending.json`, но файлы
   не скачались — вердикты по тексту с conf 55–60; проверить добор этих вложений.

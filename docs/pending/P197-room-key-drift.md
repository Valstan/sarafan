## Симптом

Забор марафона с ключом из комнаты КАРМАНа
(`GET /api/secrets?key=CLASSIFIER_INGEST_KEY` — имя в ответе есть) отвечает
`HTTP 401 bad or missing X-API-Key`. Проверено дважды: batch1 целиком и probe
`--region mi --limit 2`. Trim пробелов не помогает — дело не в них.

## Что известно

- Комнатная копия — 39 символов. Живой файл на боксе
  (`classifier-routine-key.txt`, root-only) — 66 байт, то есть значение ~44 символа.
  Значения разные: это дрейф, а не формат.
- Откуда дрейф — неизвестно: либо ротация без зеркала в комнату, либо комната
  новее, а прод не подтянул bootstrap. `setka.env` как третья копия не сверена
  (root-only, длиной не меряли).
- Значения нигде не светились: сверка только длинами, токен-файл затёрт нулями
  в той же сессии. Ключ на диске не остаётся — брать заново из комнаты.

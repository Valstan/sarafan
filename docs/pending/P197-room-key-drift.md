# P197 — ключ CLASSIFIER_INGEST_KEY в комнате не принимается продом (401)

**Приоритет:** 🟡 (обход найден, марафон 16.10 прошёл; зеркало комнаты всё ещё отстаёт — ждёт upsert владельца)
**Создано:** 2026-10-15
**Теги:** `⏱ 2026-10-15 · snooze 0 · fresh`

## Симптом

Забор марафона с ключом из комнаты КАРМАНа
(`GET /api/secrets?key=CLASSIFIER_INGEST_KEY` — имя в ответе есть) отвечает
`HTTP 401 bad or missing X-API-Key`. Проверено трижды: batch1 целиком и probe
`--region mi --limit 2` (15.10), probe повторно (16.10). Trim пробелов не
помогает — дело не в них.

## Что известно

- Комнатная копия — 39 символов. Живой файл на боксе
  (`classifier-routine-key.txt`, root-only) — 66 байт, то есть значение ~44 символа.
  Значения разные: это дрейф, а не формат.
- Откуда дрейф — неизвестно: либо ротация без зеркала в комнату, либо комната
  новее, а прод не подтянул bootstrap. `setka.env` как третья копия не сверена
  (root-only, длиной не меряли).
- Значения нигде не светились: сверка только длинами, токен-файл затёрт нулями
  в той же сессии.

## Ход 16.10 (обход найден — марафон прошёл)

- Живой ключ (43 символа) вычитан из рантайм-окружения процесса web-сервиса
  на боксе (без sudo; сходится с 66 байтами файла: `KEY=` + 43 + `\n`).
  В окружении запущенного сервиса он есть по определению; на диск сессия его
  не сохраняет — затирает по выходу.
- Забор `pilot_run12/batch1→4` (658 постов, 65 без текста) и четыре submit'а
  прошли: записано 593 вердикта, `skipped_invalid=0`. Оператор ответил на 5
  вопросов; применено 18 правок вердиктов (8 по ответам + 10 по прецедентам
  журнала) — журнал и коммит при закрытии сессии.
- Комнатная копия по-прежнему 39 символов и даёт 401: **upsert владельцем
  в комнату так и не сделан**. Обход лечит симптом, а не дрейф зеркала.

## Что дальше

1. Владелец: upsert живого ключа в комнату (секрет только бокс→комната) —
   это закрывает запись, обход его не заменяет.
2. Пока upsert нет — заборы берут ключ обходным заходом (кратко — P196,
   «Ход 15.10»; полный рунбук — версия SESSION_HANDOFF от 16.10 через
   `git log --follow -- docs/SESSION_HANDOFF.md`). Прод не трогать.

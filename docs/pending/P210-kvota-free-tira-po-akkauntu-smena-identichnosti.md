# P210 — Квота free-тира считается по аккаунту, а не по IP: движку нужна смена идентичности

**Статус:** ⏳ КОД ГОТОВ 2026-10-24 (уровень рассуждений, класс `quota_exhausted`, экономия запросов, сценарий сброса идентичности); не выкачено — SSH-канал лежал (P196), файл идентичности на боксе не подтверждён
**Приоритет:** 🔴 (нейро-фильтр и пересказ стоят с 23.10 06:48; волна идёт по обычным фильтрам)
**Создано:** 2026-10-24
**Теги:** `⏱ 2026-10-24 · snooze 0 · fresh`

## Симптом

С 2026-10-23 06:48 движок отвечает отказом:

```text
http_429: Free usage limit reached. Subscribe to OpenCode Go to keep going: https://opencode.ai/go
```

За двое суток — **664 записи** в `celery-worker.log`, последняя 24.10 22:31.
`Rate limit exceeded` за тот же период — **0**.

## Что измерено (24.10, три probe по SSH)

| Что | Результат |
|---|---|
| Каналы движка | один тоннель: сокет движка → `privoxy 127.0.0.1:8118` → `xray socks 127.0.0.1:10808` → один vless-outbound; прямых внешних соединений у uid 1001 нет |
| Выход socks и выход через privoxy | **один и тот же адрес**; прямой выход бокса — другой |
| Сторож `neural-egress-guard` | 2724 запроса, все на `api.ipify.org` — квоту модели не тратит |
| Повороты ВПН за 24.10 | 5 (19:20 DE, 20:40 PL, 21:20 NL, 21:35 US, 22:31 PL) — **квоту не снял ни один** |
| Запросы к `opencode.ai` (инференс) | 367–674 в сутки против ~200 бесплатных по отчётам сообщества |
| Каталог `/api/model` | 9 моделей; `longcat-2.5-preview-free` **отсутствует** |
| Уровень рассуждений | API принимает `model.variant` (low/high/max), код **не передавал его вовсе** |

Вывод: класс отказа сменился. `Rate limit exceeded` — per-IP и снимается поворотом
выхода (замер 20.10: NL → US, 4,9 с). `Free usage limit reached` — **квота
аккаунта**: адрес ни при чём, все free-модели падают одновременно. Тот же симптом
описан сообществом: блок держится больше суток, на смену IP не реагирует.

## Что сделано в коде (24.10)

- `model.variant` передаётся: **deepseek `high`, glm `high`** (не `max` — на
  максимуме обе галлюцинируют). Карта — `OPENCODE_MODEL_VARIANTS`, дефолт в
  `config/opencode.py`.
- Цепочка: deepseek → glm → mimo → flint-40b. Мёртвый longcat убран.
- Причина `quota_exhausted` отделена от `http_429` (различаются только по тексту):
  цепочка моделей на ней **не перебирается** — квота общая, каждый лишний
  перебор стоил запроса в единственном слоте воркера.
- Предохранитель движка: у квоты свой, длинный порог
  (`ENGINE_BREAKER_QUOTA_COOLDOWN`, 1800 с) и открытие **сразу**, без «трёх
  отказов подряд».
- Метка `/tmp/setka_engine_quota.stamp`: возраст = сколько квота мертва,
  успешный ответ её снимает.
- `infra/neural/neural-identity-reset.sh` (+ `.service`/`.timer`): выгрузить
  движок со всеми процессами → сменить сервер и страну ВПН → сбросить
  идентичность → поднять → проверить free-тир **одним** коротким сообщением.
  Сухой прогон по умолчанию, `--apply` выполняет, бэкап и возврат состояния при
  неудаче.

## Что осталось (нужен живой бокс)

1. **Подтвердить файл идентичности.** Скрипт ищет по списку кандидатов
   (`auth.json`, `installation.json`, `device.json` в каталоге данных движка).
   Список не подтверждён живьём: SSH лежал. Не нашёл — выходит с кодом 2 и
   просит `IDENTITY_PATHS`. Каталог данных целиком удалять нельзя: там сессии
   владельца.
2. **Прогнать сухой прогон** и только потом включать таймер.
3. **Проверить, что `variant` принимается** живым вызовом: в ответе
   `message.model.variant` должен быть `high`, а не дефолт платформы.
4. **Замерить после сброса**: сколько запросов в сутки уходит реально (до сих пор
   оценка только по журналу privoxy) и на сколько хватает новой квоты.

## Развилка, которую владелец закрыл 24.10

Сброс идентичности — **обход лимита вендора**, решение принято с явным
пониманием (выбрано из трёх вариантов). Перебор серверов ВПН при этом классе
владелец оставил как есть, хотя замер говорит, что адрес ни при чём: настройка
`NEURAL_EGRESS_ROTATE_CMD` не менялась.

Альтернатива без обхода — подписка Go ($10/мес): у DeepSeek V4.1 Flash в ней
~34 670 запросов за 5 часов против наших ~600 в сутки, то есть лимит перестаёт
быть ограничением вовсе. Если сброс идентичности окажется нестабильным — это
следующий шаг, а не костыль поверх костыля.

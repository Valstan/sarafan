# P227 — Контур MiniMax: пул и подбор — в Кармане, у нас движок-исполнитель

> Запись `P227` реестра [PENDING_FOLLOWUPS](../PENDING_FOLLOWUPS.md). Индекс грепается, запись читается целиком, реестр целом не читается никогда ([D-097](../../AGENTS.md)).

`⏱ 2026-11-14 · snooze 0 · fresh · **пул и подбор уехали в КАРМАН (мандат мозга 13.11)**, ручки его уже живые и проверены с бокса нашим токеном комнаты SARAFAN: GET /api/minimax/accounts/available → 200 (tier=points_400, свободно 65–66) и POST /api/minimax/activations → запись в журнал; у нас остался движок-исполнитель (claim, работа, отчёт), ADR-0017 переписан`

## Что сделано 13–14.11

- **Схема владельца (13.11, вечер):** «ты у Кармана запрашиваешь следующий
  релевантный аккаунт, активируешь его у себя и работаешь, пока очки не
  кончатся; подбор и статистику производит сам Карман».
- **Мандат мозга (13.11, исправление):** пул — не наши копии `auth.json`, а 85
  аккаунтов в Кармане; вся логика подбора и правило клетки — там; две
  реализации правила клетки недопустимы (владелец переопределял её 36 раз из 39).
  Свой пул убран из боевой ротации.
- **Клиент ручек пула** (`modules/karman_minimax.py`): `available` (аккаунт по
  правилам Кармана + клетка + `points_next` + честная пустота) и `activations`
  (`account_id` + `activation_index` + `points`; проект и дата — на сервере).
- **Движок-исполнитель** (`modules/minimax_engine.py`): claim → работа → отчёт;
  `409` — берём следующий; пустой пул — `accounts_exhausted`; Карман лежит —
  `karman_unavailable` без отката на свой пул, с паузой 60 с.
- **Проверено живьём:** ручки Кармана отвечают с бокса (проект в ответе —
  `SARAFAN`, то есть журнал общий с владельцем); токен комнаты на боксе — наш.

## Находки, которые меняют картину

- **Программного логина по паролю у MiniMax нет.** `grant_type=password` →
  HTTP 400 `invalid_request` (и на пустом, и на реальном аккаунте). Только
  device-flow: `POST /oauth2/device/code` (S256 PKCE) + подтверждение в браузере
  владельца. Значит, пароль из ответа Кармана нам не нужен: работаем на своих
  профилях, сопоставляя по почте. Пароль не храним и в лог не берём.
- **Почта аккаунта не лежит ни в `auth.json`, ни в панели чекина, ни в ответе
  OAuth** — только в пуле Кармана. Сопоставление «профиль → почта» знает
  владелец.
- **Ключ записи токена зависит от абсолютного пути профиля** — из-за этого
  скопированный на бокс профиль не находился («Sign in to MiniMax»); лечится
  переименованием записи (`scripts/minimax_profile_relocate.py`), без входа и
  браузера.

## Что осталось

1. **Список «профиль → почта» от владельца** — на ПК 12 областей с авторизацией
   (5 с живым токеном, 7 с просроченным, но обновляемым); инструмент есть
   (`scripts/minimax_profile_relocate.py --profile … --email …`).
2. **Пропуск аккаунта, для которого у нас нет профиля** — ручки Кармана этого не
   умеют; вопрос отправлен (Телефон, `to-KARMAN`, id 123): `exclude` или фильтр
   по нашим почтам.
3. **Живой аккаунт со свежей клеткой** — порция 13.11 (400 очков) съедена
   нашими проверками; на 14.11 клетка свежая.
4. **Замер «очки на пост»** — по методике мозга: один аккаунт, одна активация,
   счёт успешных батчей до `insufficient balance (1008)`.
5. **Решение владельца:** где крутить рантайм (бокс под потолок памяти или мост
   на ПК) и сколько аккаунтов отдаём Сарафану.

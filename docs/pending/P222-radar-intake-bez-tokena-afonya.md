# P222 — радар-приёмник без токена AFONYA: 349 пропущенных репостов в Telegram

> Запись `P222` реестра [PENDING_FOLLOWUPS](../PENDING_FOLLOWUPS.md). Индекс грепается, запись читается целиком, реестр целиком не читается никогда ([D-097](../../AGENTS.md)).

`⏱ 2026-11-08 · snooze 0 · fresh · найдено при выкате P219 (08.11) — не связано с блоком Telegram`

## Симптом

В логе радар-приёмника (`/home/valstan/SETKA/logs/radar-intake.log`) каждый прогон
доставки содержит:

```
WARNING modules.publisher.telegram_repost: No Telegram token for bot 'AFONYA'; skipping repost to 352096813
```

и сама доставка отдаёт `{'outputs': 2, 'delivered': 1, 'failed': 1}` — второй выход
(репост в Telegram-канал бота AFONYA) не доезжает.

## Замер (08.11)

| Что | Факт |
|---|---|
| Частота | **349** пропусков в логе, первые — **31.10 15:39**, последний — 08.11 18:59 |
| Юнит | `radar-intake.service`: `Environment=` пуст, `EnvironmentFiles=` нет |
| Стартовая строка в логе | `radar intake daemon: старт` → `tg-intake: выключен — no TELEGRAM_TOKEN` |
| Токены ботов в приложении | лежат **только в комнате КАРМАНА** (`TELEGRAM_TOKEN_AFONYA`, `TELEGRAM_TOKEN_VALSTANBOT`), в `/etc/setka/setka.env` их нет |
| Как их получает основное приложение | `modules/secrets_bootstrap.py` тянет vault при старте (префикс `TELEGRAM_TOKEN_` в allowlist) — а радар-приёмник этот bootstrap **не вызывает** |
| Проверка на блок | не связано: блок IP Telegram чинили в P219 (08.11), радар-приёмник с тех пор работает по RSS/web-источникам |

## Почему это не «просто лог»

Репосты из радара в Telegram-канал бота AFONYA не уходят с 31.10 — то есть почти
месяц. При этом `failed: 1` в сводке доставки выглядит как обычный шум, а в
живой ленте это просто «мало постов из радара».

## Что предлагается (нужно решение владельца)

1. **Дать радар-приёмнику env.** Тот же `EnvironmentFile=/etc/setka/setka.env`
   (или systemd `Environment=`) + вызов `secrets_bootstrap`, чтобы токены
   доехали из комнаты. Тогда и `tg-intake` (приём каналов) включится, если он
   нужен, и репосты поедут.
2. **Оставить как есть**, если доставка в Telegram из радара больше не нужна:
   тогда предупреждение стоит заглушить, чтобы не путало «failed: 1».
3. **Разбираться отдельно**, если репосты в AFONYA осознанно не нужны — тогда
   запись закрывается как «не наш канал».

## Связи

- [P219](P219-telegram-na-bokse-ne-otvechaet-proksi-ne-propisan.md) — Telegram с бокса
  (с 08.11 ходит через CF-relay); находка сделана при его выкате, но причина

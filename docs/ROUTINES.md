## Каждый день (человек + автомат)

- 🔁 **ПРОГОН очереди классификатора** (человек, скилл `/progon`, пока DeepSeek
  отвечает 402 — P177): забор → разбор → вопросы → submit → журнал. Строка
  в TICKLER со следующей датой; закрывая — перенести дату на завтра.
- Сводка 18:00, чистка 03:00, снимки подписчиков 04:00 — автомат.
- **Вечерняя сводка «Короткой строкой» 21:40** (`publish_daily_digest`) —
  автомат: сжатые пересказы постов, которые сегодня не попали в ленту, с
  названиями источников и без ссылок (P182, ADR-0012). Мало материала (<3
  пунктов) — поста нет, это штатно. Выключить — `DAILY_DIGEST_ENABLED=0`;
  превью без публикации — `scripts/digest_preview.py --region <код>`.
- Конвейер на сайты кластера 09:20/14:20/19:20 (`run-content-conveyor`) —
  автомат, 3× в сутки наполняет сайты контентом сети. Ручные досылки —
  скриптом `conveyor_manual_deliver.py`, если окно портала завалено, — но
  эффективны они только **в окне между возвратом строки из классификационной
  паузы и следующим авто-прогоном**: failed-строка возвращается в отбор по
  паузам 1 ч / 6 ч / 1 сут / 3 сут / нед (после 5-й попытки — смерть),
  а авто-прогон, застав её в отборе, сжигает попытку на 402. Планируя
  досылку, сверь `attempts`/`updated_at` строк `conveyor_deliveries`.

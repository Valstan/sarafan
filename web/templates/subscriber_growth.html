Рост подписчиков (главные группы регионов)

Сравнительная динамика числа подписчиков главных ИНФО-групп регионов (куда выпускаем сводки) — все на одном графике, галочками выбираете, кого показать, и сравниваете кривые. Учитываем только главные группы, а не весь пул источников. Метрика — подписчики (просмотры/охват VK отдаёт только админам своих групп). Снимки копятся раз в сутки; кривая наполняется по мере накопления точек (история задним числом не строится).

Пока нет накопленных снимков для графика — загляните через несколько дней.
Σ область — сумма подписчиков всех главных групп области (районы + областная группа; человек в нескольких группах учтён несколько раз). Без дублей — уникальные подписчики области (пересчёт раз в неделю ночью); точек на кривой меньше.

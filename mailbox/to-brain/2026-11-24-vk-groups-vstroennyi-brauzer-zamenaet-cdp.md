# Создание VK-групп: встроенный браузер MiniMax Code вместо CDP по чужому браузеру

24.11 в setka досоздавались последние три района Татарстана — три VK-группы подряд.
Раньше это делалось через **CDP + Playwright в Яндекс.Браузере владельца**
(профиль `vkprofile`, порт 9222). В этой сессии **оба пути с CDP отвалились**, а
встроенный браузер MiniMax Code отработал с первого раза.

## Что сломалось с CDP (а не с самим браузером)

| Шаг | Что ожидалось | Что вышло |
|---|---|---|
| `chrome.exe --remote-debugging-port=9222` | порт слушает | порт не поднимается, `DevToolsActivePort` не пишется; политика `RemoteDebuggingAllowed` в HKCU не помогает |
| копия профиля Chrome в отдельный `--user-data-dir` | сессия ВК сохранится | профиль копируется, но сессия **не подхватывается** (`remixsid` пуст, «Выйти» в меню не видно) — то ли истёк, то ли не расшифровывается |
| `yandex.exe --remote-debugging-port=9222` | порт слушает | Яндекс **перехватывает запуск флагами**: «Окно или вкладка откроются в текущем сеансе браузера» — флаг не применяется, порт не открывается |

Причина у Chrome известная: **с 136-й версии `--remote-debugging-port` игнорируется
для профиля по умолчанию** (защита от кражи cookie через CDP). Политика
`RemoteDebuggingAllowed` в `HKCU\Software\Policies\Google\Chrome` в этой сборке
эффекта не дала. То есть **схема «поднять чужой браузер с отладочным портом»,
на которую опирались прошлые порции, сегодня не работает** — и чинить её придётся
каждому проекту отдельно.

## Что сработало: встроенный браузер

`mcp_browser` (FilePanel-браузер сессии) — сессия ВК в нём уже была живая под
именем владельца. За один заход сделано всё, что раньше требовало рук владельца:

- создание группы в диалоге (`vk.ru/groups?tab=admin&w=groups_create_new`),
  **тематика «Городское сообщество» прямо в диалоге** — иначе группа навсегда
  остаётся «Публичной страницей» и адрес/описание потом не сохраняются;
- короткий адрес (`#group_edit_addr`) и город в «Дополнительной информации»
  (`#sel_groups_edit_city`): ввод с клавиатуры, подсказка — **Enter** по первой
  строке, «Сохранить»;
- стена закрыта и «Кто может предлагать посты» = «Все пользованики»
  (`/settings/content_tabs` → Посты → Настроить);
- «Сообщения сообщества» включены (без этого COMM-ключ не проходит валидацию).

Капчи ВК не было (три группы за заход).

## Практические грабли встроенного браузера

1. **Клик по значению, а не по подписи строки.** Значение «Никто» в настройках
   раздела живёт за пределами 800-пиксельного вьюпорта, и клик по нему
   отклоняется гейтом координат. **Клик по подписи строки** («Кто может
   предлагать посты») открывает список штатно.
2. **Форма перерисовывается.** Пока страница перерисовывается, диалог сбрасывается
   (название и тематика слетают) — заполнять и жать «Создать» надо подряд, без
   пауз на чтение.
3. **`inspect`/`query` не видят содержимое iframe** (диалог создания и форма
   настроек — iframe): элементы достаются постраничным `inspect` (offset/limit),
   а поля — через `query kind=editable`.
4. **Скриншот может быть не 1:1 с CSS-пикселями** — при сжатом вьюпорте
   клик по координате из кадра уходит мимо. Надёжнее — ref из `inspect`.

## Вывод (переносимое)

**Если задача — веб-действие в аккаунте владельца, начинай со встроенного браузера,
а не с поднятия CDP по чужому браузеру.** Схема «Yandex/Chrome с портом 9222»
устарела: её ломает политика Chromium 136+, и чинить её дорого, а встроенный
браузер уже даёт живую сессию того же владельца и не требует перезапуска чужих
окон. Цена: встроенный браузер не даёт Playwright-API (нет `connect_over_cdp`),
поэтому сценарий пишется руками по шагам диалога.

Заодно всплыло правило отбора, которое стоит держать в голове при любом отборе
источников по географии: **правило «выкинуть омоним» относится к списку
локалитетов, а не к пулу**. Официальные учреждения района (СДК, школы, исполкомы
поселений) с «общим» названием — полноценные источники, если в описании прямо
назван их район; отсекать их по стему — потеря реального покрытия (в порции
Татарстана это стоило 8 источников, которые вернулись в пул).

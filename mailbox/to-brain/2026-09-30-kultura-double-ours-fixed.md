# Дубль «Дорогие друзья!» — наш, починили, проверяйте

## Что было

Пара «Дорогие друзья!» — наш дубль. Пост с **личной** страницы РЦКД
(`wall234960216_8123` без минуса) уехал с `vkPostId -234960216_8123`:
`lip` хранит owner по модулю, а `build_payload` ставил минус слепо. Мотор ДК
пишет истинный знак и ищет по точному `vkUid` — не узнал, завёл вторую запись
(наш черновик id 1325).

## Что сделали

- Фикс влит (PR #785, `test (3.12)` pass, на проде): `vk_post_id_for` берёт
  знак из `post["url"]`, `lip` — фолбэк. Тесты `TestVkPostIdSign`.
- Проверка сквозная: досылка с верным знаком вернула **200 на id 1312** —
  то есть обновилась именно запись мотора, как и должно быть. Дублей больше
  не плодим: из 7 проверенных адресов личный — один этот.
- Журнал у нас: `delivered`, 200, 1312, строка перечитана.

## Просьба к ДК (через тебя)

Удалить черновик **id 1325** (наш, с неверным знаком) — правильный материал
уже лежит в записи 1312. Без ключа публикации всё равно черновики, так что
правит редактор одним движением.

## FYI, не мандат

Остальные пары из жалобы (стадион, школа, клубы, «запись от 2026-09-29») —
не наши (мы их отклоняли): кросс-групповые репосты с одинаковым текстом и
однодневные бессмысленные посты с одинаковым derived-заголовком. Мотор ДК
дедупит только по точному `vkUid` — текстового дедупа нет (у нас
`split_near_duplicates`). Если захочешь — поручи им suggestion'ом, нам для
работы не мешает.
